## 更新時の注意

- 実在確認できない値を推測で追加しない。
- 同じ商品名でも容量が違う場合は別の商品として登録する。
- `ProductSeeder`は実商品マスタ専用とし、#27の架空の自販機・価格・ポイントは別の開発用シーダーに置く。
- 本番データを消す処理や`migrate:fresh`はシーダーに含めない。

## 商品説明(description)の根拠(#62)

2026年10月20日に、各メーカー公式サイトの原材料名・栄養成分表示・カフェインの記載を確認した。
「確認した事実」は公式ページに書かれている内容、「RAG用の判断」は確認した事実から説明文に書いた分類である。

### 説明文の言葉の決め方

| 説明文の言葉 | 判断の基準 |
|---|---|
| 甘い / 加糖 | 原材料名に砂糖類(砂糖、果糖ぶどう糖液糖、果糖など)がある |
| 甘味料で甘い / 甘味料使用 | 原材料名の「/」より後ろ(添加物)に甘味料がある |
| 甘くない | 糖類0g または炭水化物0g で、かつ甘味料がない |
| 微糖 | メーカーが「微糖」と表示している |
| 炭酸飲料 / 炭酸水 | 原材料名に「炭酸」がある |
| 炭酸なし | 原材料名に「炭酸」がない(判断) |
| カフェインあり | 公式のカフェイン量が0より大きい、または原材料名に「カフェイン」がある |
| カフェインゼロ | 公式のカフェイン量が0mg、またはメーカーが「カフェインゼロ」と表示している |
| カフェインなし | 公式にカフェイン量の記載がなく、原材料に茶葉・コーヒー・カフェインがない(判断) |
