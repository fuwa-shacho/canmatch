# 読み取りの評価(Issue 07)

`evals/photos/` の写真を AI(Gemini)で読み取り、`evals/answers.json` の正解と比べて正解率を出します。

## 実行

```bash
./vendor/bin/sail artisan eval:reader
```

`.env` に `GEMINI_API_KEY` と `GEMINI_MODEL` が必要です。

| オプション | 用途 |
|---|---|
| `--photo=09_suntory.jpg` | 指定した写真だけを読む(複数指定できる) |
| `--model=...` | モデルを変えて比べる(省略時は `GEMINI_MODEL`) |
| `--prompt=...` | 指示文を変えて比べる(`resources/prompts/<名前>.md`) |
| `--dir=evals/photos-2000` | 縮小サイズを変えた写真のフォルダで比べる |
| `--sleep=5` | 写真ごとの待ち時間(秒)。1分あたりの上限を超えないため |
| `--details` | 外れた正解の行と、正解にない読み取りを写真ごとに表示する |
| `--save=...` | 結果の JSON の保存先(省略時は `storage/app/evals/`。コミットしない) |

## 数え方

正解の1行(商品名・価格・温冷)ごとに数えます。`count`(同じ商品が並ぶ列の数)は点数に使いません。

| 項目 | 正解とみなす条件 |
|---|---|
| 商品名 | 読み取り結果に、同じ商品名の行がある |
| 価格 | 同じ商品名の行のどれかが、正解と同じ価格 |
| 温冷 | 同じ商品名の行のどれかが、正解と同じ温冷(正解の温冷が `null` の行は数えない) |
| すべて一致 | 同じ商品名の行のどれかが、価格と温冷の両方で一致 |
| 正解にない読み取り | 正解のどの行とも商品名が合わない読み取り(読み間違い、存在しない商品) |
| 価格を空にした数 | AI が価格を `null` にした行(読めない項目を空にできたか) |

商品名は、全角・半角、大文字・小文字、空白、記号(・ - . など)の違いをそろえてから比べます。

- **厳しめ**:`name` か `aliases` のどれかと完全に一致
- **ゆるめ**:厳しめに加えて、どちらかがもう一方を含む(2文字以上)。例:「絶品微糖」と「ダイドーブレンド 絶品微糖」

## 使うリクエスト数

写真1枚につき1リクエストです。10枚なら1回の実行で10リクエスト(429 のときだけ1回再試行するので、最大20)。
無料枠の1日あたりの上限は、Google AI Studio のレート制限ページで確認してください(Issue 16)。

## 比べ方の決まり

指示文、モデル、縮小サイズを変えるプルリクエストでは、変更の前と後で同じ写真を使ってこのコマンドを実行し、
「合計」の表をプルリクエストの本文に貼ります。
